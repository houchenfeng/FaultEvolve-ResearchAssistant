# FaultEvolve 视觉系统 v2（天猫 AI 黑客松路演版）

一句话定位：**几何极简 + 一种强调色 + 丝滑但克制的运动**。产品、PPT、宣传片共用同一套 token、同一个标志、同一套运动曲线。

## 1. 现状问题

| 载体 | 现在的样子 | 问题 |
|---|---|---|
| 前端 `web/src/styles/theme.css` | 微软 Fluent：`#0078d4`、Segoe UI、亚克力毛玻璃、阴影 | 像 Windows 设置页，不像 AI 产品；13px 字号信息密度过高 |
| 图标 `faultevolve-icon.svg` | 蓝绿双渐变、脉冲线、粗树干 | 细节多，小尺寸糊；与“极简几何”方向冲突 |
| 首页 hero | 位图背景 `faultevolve-hero-bg.png`（2 MB） | 风格和其他页面断开 |
| 进化树 / 知识页 | 红黄绿蓝紫多色卡片、虚线实线混用 | 颜色语义过多，路演投屏时看不出重点 |
| 旧宣传片 | 白底 + 手绘硬盘表情包 + 手写字 | 偏可爱，与“科学发现 / 可审计”调性不符 |
| 组件 | `routes/`、`features/` 中仍有 38 处硬编码色值 | 换主题时会漏改 |

## 2. 设计原则

1. **几何即语义**：圆 = 候选节点，线 = 演化分支，箭头 = 进化方向，方框 = 本地沙箱。所有图形只用这四种元素。
2. **一种强调色**：画面中 90% 是黑白灰，强调色只给“当前最优 / 正在发生的事”。
3. **数字是主角**：ROS 22.81 → 36.50、n = 9,262、33 个候选——大号等宽数字，少写形容词。
4. **运动只表达因果**：生长、连接、穿过边界，不做无意义的漂浮和旋转。

## 3. 标志

草稿：[`brand-mark-draft.svg`](brand-mark-draft.svg)。一个由演化树构成的 “F”：

- 竖线 = 主干，底部实心圆 = 初始候选；
- 中间横枝末端的空心圆 = 正在本地评估的候选；
- 顶部横枝末端的箭头 = 进化出的最优方向，唯一带强调色的部分。

用法：单色（`currentColor`）+ 箭头强调色；最小 16px；字标用 `FaultEvolve`，Inter / Geist 600，字距 -0.02em。替换现有 `public/assets/faultevolve-icon.svg` 和 favicon。

## 4. 颜色

深色为主（路演、PPT、视频），浅色为产品日常使用。两套共享同一个强调色。

| Token | 深色 | 浅色 | 用途 |
|---|---|---|---|
| `--fe-canvas` | `#0A0A0B` | `#FAFAFA` | 背景 |
| `--fe-surface` | `#141416` | `#FFFFFF` | 卡片 |
| `--fe-surface-muted` | `#1C1C1F` | `#F4F4F5` | 次级面板、输入框 |
| `--fe-border` | `#26262A` | `#E4E4E7` | 1px 分隔线（不用阴影） |
| `--fe-fg` | `#F5F5F5` | `#0A0A0B` | 正文 |
| `--fe-fg-muted` | `#A1A1AA` | `#52525B` | 说明文字 |
| `--fe-fg-subtle` | `#52525B` | `#A1A1AA` | 占位、刻度 |
| `--fe-accent` | `#3D5AFE` | `#3D5AFE` | 唯一强调色：最优节点、主按钮、进化箭头 |
| `--fe-discovery` | `#C6F432` | `#65A30D` | 只用于“新知识 / CONFIRMED” |

状态色降饱和、只出现在小圆点和小标签上，不做整块底色：

| 语义 | 色值 | 现有对应 |
|---|---|---|
| 成功 / 注入成功 | `#22C55E` | 替换 `#00cc6a` |
| 失败 / 剪枝 | `#EF4444` | 替换 `#e81123` |
| 待定 / 停滞 | `#F59E0B` | 替换 `#ffb900` |

三岛（时序特征 / 模型集成 / 运维阈值）不再用蓝紫绿三种底色，改为同一灰度底 + 不同几何标记：● 实心圆、○ 空心圆、◆ 菱形。

## 5. 字体与排版

- 中文：`HarmonyOS Sans SC`（免费可商用）→ 回退 `PingFang SC`、`Microsoft YaHei`。
- 西文 / 数字：`Inter`（或 `Geist`），数字一律 `tabular-nums`。
- 代码 / ID / 指标：`JetBrains Mono`。

| 级别 | 产品 | PPT / 视频（1080p） |
|---|---|---|
| Display | — | 120–160px / 700 / 字距 -0.03em |
| H1 | 24px / 600 | 64px |
| H2 | 18px / 600 | 40px |
| Body | 14px / 400（从 13px 提升） | 28px |
| Caption | 12px / 400 | 20px |
| 指标数字 | 28–40px Mono | 160–240px Mono |

## 6. 形状、间距、质感

- 圆角：卡片 12px、按钮 8px、标签 999px。只有这三种。
- 间距：4px 基数，常用 8 / 12 / 16 / 24 / 40 / 64。
- 质感：去掉 Fluent 阴影和亚克力，改为 1px 边框 + 背景层级区分。唯一允许的“光效”是强调色节点的 0 0 24px 外发光。
- 背景：深色模式下 24px 点阵网格（`--fe-border` 颜色，透明度 40%），替代 2 MB 的 hero 位图。

## 7. 运动规范

| Token | 值 | 用途 |
|---|---|---|
| `--ease-out` | `cubic-bezier(0.16, 1, 0.3, 1)` | 元素进入、展开 |
| `--ease-in-out` | `cubic-bezier(0.65, 0, 0.35, 1)` | 镜头移动、形变 |
| `--dur-fast` | 150ms | hover、按下 |
| `--dur-base` | 300ms | 面板、抽屉 |
| `--dur-slow` | 600ms | 页面进入、节点生长 |

产品内动效：

- 进化树节点逐个出现：缩放 0.6 → 1 + 透明度，间隔 40ms；连线用 `stroke-dashoffset` 绘制。
- 新最优节点出现时，强调色圆环向外扩散一次（只一次）。
- 数字变化用滚动计数（≤ 600ms），不闪烁。
- 删除所有 `hover:-translate-y-*` 的上浮效果，改为边框颜色变化。
- 保留 `prefers-reduced-motion` 降级。

## 8. 前端统一改造清单

按影响从大到小：

1. **重写 `theme.css` token**：替换为第 4–7 节的变量；`data-theme='dark'` 设为路演默认。
2. **清理硬编码色值**：`routes/`、`features/` 下 38 处 `#xxxxxx` 和 `.fe-*` 组件类里的 `#0078d4`、`#e1e1e1` 全部改用 token。
3. **换标志和字体**：替换 `faultevolve-icon.svg`、favicon；引入 Inter + HarmonyOS Sans。
4. **首页**：删掉位图 hero，改为“大号指标 + 三步流程（云端提出 → 本地评估 → 知识发现）”的几何示意。运行配置表单折叠到“设置”抽屉，首页不再出现大段表单。
5. **进化树 `TreeCanvas` / `TreeNodeCard`**：节点卡片缩小为“圆点 + ROS 数字”，悬停再展开详情；岛屿底色改为统一灰度；跨岛注入线只保留成功（强调色实线）和失败（灰色虚线）两种。
6. **知识发现页**：顶部 CONFIRMED 用 `--fe-discovery` 单色徽章；六步证据链做成一条横向时间轴（圆点 + 连线），替代六张卡片。
7. **新增“路演模式”**：顶栏一个开关，切深色、隐藏配置项、字号整体 ×1.25，便于投屏。

## 9. 宣传视频方案（60 秒，HyperFrames 制作）

风格：黑底、白色几何线条、唯一强调色；无吉祥物、无手写字。节奏由一条低频电子乐 + 每个节点出现时的短促“滴”声驱动。

| 时间 | 画面 | 字幕 |
|---|---|---|
| 0–5s | 黑屏中一个白点出现，轻微呼吸 | 一块硬盘，会在什么时候坏？ |
| 5–12s | 白点分裂成上百个灰点（候选算法），大部分熄灭 | 工程师调一个算法，要几周。 |
| 12–20s | 屏幕被一条横线分为上下两半：上方“云端”，下方“本地沙箱”。一个圆从上方落下，穿过边界进入方框，只有一个数字返回上方 | 大模型在云端提出假设。数据从不离开本地。 |
| 20–32s | 三棵树从左向右同步生长（三岛），失败分支变灰虚线，一条强调色连线跨岛连接 | 三个岛并行进化，好的想法跨岛迁移。 |
| 32–40s | 镜头推向最优节点，等宽数字从 22.81 滚动到 36.50 | ROS 22.81 → 36.50 |
| 40–50s | 节点展开为一行文字“窗口末端 SMART 194 → 故障风险上升”，下方证据链六个圆点依次点亮，最后亮起 `CONFIRMED`（荧光绿） | 它不只调参。它发现了新知识。n = 9,262，经多重检验确认。 |
| 50–56s | 所有线条收拢成标志 “F” | 提出假设，亲自检验，写下新知识。 |
| 56–60s | 标志 + 字标 + 天猫 AI 黑客松字样 | FaultEvolve |

制作要点：

- 1920×1080 / 60fps 主版本，另出 1080×1920 竖版用于社媒。
- 所有图形用 SVG + GSAP 时间线，不用位图，保证 4K 投屏清晰。
- 第 12–20s 的“云端 / 本地边界”是整片的核心视觉，PPT 架构页复用同一张图。
- 产品实拍只在 20–32s 之后叠 2–3 秒，且必须是换完新主题后的录屏，否则风格会断。

## 10. PPT 与视频的对应关系

PPT 直接复用视频的分镜作为章节页，保证路演时“视频 → 讲解”无缝衔接：

1. 问题（一块硬盘）→ 2. 架构（云端 / 本地边界）→ 3. 自进化（三岛树）→ 4. 结果（大数字）→ 5. 新知识发现（证据链 + CONFIRMED）→ 6. 产品演示 → 7. 结尾（标志）。

## 11. 建议执行顺序

1. 确认标志草稿和强调色（半天）。
2. 改 `theme.css` + 清理硬编码色（1 天），截新图。
3. 用新截图和本规范做视频（1–2 天）。
4. PPT 复用视频素材（半天）。
