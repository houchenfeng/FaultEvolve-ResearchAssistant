# HDD 深度学习持续实验

基线版本：FaultEvolve-huawei `815e582`。开发分支：`codex/hdd-deep-evolution`。

## 当前实现与边界

新增独立实验入口 `experiments/hdd_dl/controller.py`，不改变旧 CLI、任务评估器或数据。
控制器提供训练数据画像、ML/DL 先验路由、自动文献元数据检索、文献/任务知识卡注入、
残差 MLP、轻量时序卷积与 GRU 种子、多目标有效候选反馈驱动的配置变异、
有限批次、断点续批、停止文件、逐项基线比较与证据记录。不是任意网络源码生成，也尚未接入主三岛调度。
知识卡是可追溯先验，不是已验证发现。每个新批次自动执行两次 Crossref 查询并冻结结果，
恢复同一批次不再检索；自动卡片标记 `bibliographic_metadata_only`，标题只映射受支持的模型家族假设，
不宣称读过全文、复现论文或证实其效果。

网络读取公开训练与查询输入，默认按训练盘随机分层留出 20% 做早停和告警阈值校准。
新增可选三折训练集内交叉验证，拼接 OOF 预测校准阈值，查询预测取折模型平均。
标准化或分位数变换参数仅拟合各折内部训练盘。保留校准时的模型，不对全部训练盘再拟合。
内部随机划分不是跨时间泛化证明；外层仍使用固定 Q3→Q4 评估。
时序输入按真实日历保留缺天、数值缺失掩码。候选不打开验证标签。

评估使用未修改的 `benchmark/hdd_mvp/evaluator.py`，900 秒硬超时、600 秒以上时间惩罚不变。
验证集用于研究搜索，因此结果均为搜索验证结果，不是独立测试结论。
最终仍需新种子复验及单独的最终保留集裁决；本工具不读取私有测试集。

## 指标与机器学习对照

同一次运行重评初始逻辑回归和指定的历史 ML 最优程序，冻结源码哈希。
严格逐项比较 ROS、precision、recall、F1、F1_p10、AUPRC、R@FAR、quality、
误告率和漏告率；另比较 bootstrap 标准差与运行时间。
`alarms_per_1k_disks` 是运行负担描述量，不一概越低越好，保留原始值但不列为单调目标。
缺失指标、无效候选、相等值均不算严格超过。报告同时保留
`all_predictive_strictly_better` 与 `all_including_resources_strictly_better`。
单次全部超过也不等于统计显著，`independent_replication` 在完成复验前恒为 false。

## 运行位置与空间控制

- 本地独立环境及锁：`/home/hcf/faultevolve-dl/`。
- 新项目产物：`/home/hcf/nas_hcf_data/faultevolve-dl/runs/`。
- 下载缓存：NAS 新项目 `cache/`；评估短期暂存：本地 `scratch/evaluator/`。
- 本轮模型仅在内存中训练，不保存逐 epoch 检查点；交付物是可从公开输入重训的候选源码。
- 开始及每次试验前验证 CIFS 挂载源、系统盘至少 150 GiB、NAS 至少 100 GiB、单活动目录不超过 50 GiB。
- 本版本串行评估并用主机锁防止重复派发；只占一张 GPU，避免并发影响运行时间对照。
- 原评估器会复制四个公开输入到临时目录；CIFS 不支持其 `copy2/utime` 元数据操作，
  因而保留受限本地暂存，单次公开输入限制 1 GiB、启动前暂存总量限制 5 GiB，正常退出自动清理。
  控制器被强杀可能留下暂存，需后续按活动进程和目录归属核实后回收，禁止盲目清理。
- NAS 中断或空间检查失败会停止派发。既有实验与 NAS 原数据不修改。

示例（先完成独立环境与代码部署）：

```bash
/home/hcf/faultevolve-dl/env/bin/python experiments/hdd_dl/controller.py \
  --repo /home/hcf/faultevolve-dl/code \
  --output /home/hcf/nas_hcf_data/faultevolve-dl/runs/initial_20261020 \
  --baseline /home/hcf/faultevolve-dl/code/benchmark/hdd_mvp/init.py \
  --baseline /path/to/frozen/historical/best.py \
  --trials 24 --hours 8 --gpu 0
```

同一参数重新运行恢复已完成试验；模板、知识卡、公开输入、评估器或基线源码变化必须新建运行目录。
在运行目录创建 `STOP` 文件会在当前评估结束后停止。
重大更新通过测试和真实运行检查后提交并推送；指标不达标必须保留差距，不能改评估器或放宽口径。

### 加权CVaR原型数学验证

candidate.py新增WeightedTailRisk独立原型，尚未接入训练循环或默认配置。
每个正样本有持久阈值s，配对损失为softplus(负logit-正logit)；风险为
s + 加权负样本均值[max(loss-s,0)]/beta，正样本再按权重平均。
模型梯度使用更新前阈值；状态按1-加权尾部质量/beta更新并限制非负。
辅助状态是buffer，每个模型必须独立实例化，不参与Adam模型参数优化；
update=False允许只计算而不改变状态。单类或零有效权重批次返回可微零。
重复或越界样本ID、非法权重/标签/区域拒绝；不含任何外部标签或文件读取。

显式小样本公式、双精度数值梯度、权重整体缩放不变、正样本ID持久更新、
模型实例隔离、只读计算、单类处理和非法区域测试通过；服务器code-v53完整
211项测试通过。这个分批加权适配不是官方SOPA逐行复现，不声称继承收敛保证。
下一步接入有限的BCE预训练后微调，使用局部训练ID，保持验证不更新状态，
再进行GPU烟测和冻结配对。当前没有新性能分数，不晋升模型。

### CVaR训练接入与冻结对照

tail_risk_weight默认0；实验组前10轮仅原BCE，之后加入0.01加权尾部损失，
beta=0.002、辅助阈值步长0.0001。保持原总轮数/时间预算、AP早停和最佳权重选择，
