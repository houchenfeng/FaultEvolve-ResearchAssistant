## 内存：沿用赛事定义

内存任务使用官方事件、提前量、命中窗和评分口径，不把赛事口径改成通用器件的自定义标签。交付材料核实的官方规则本地考卷最佳 **F1=0.1980**；该数字来自内存方向交付包的结论归档。完整过程、缺陷修复和复算边界见 `docs/runs/smartmem-existing-attempt-analysis.md` 以及内存线交付材料，不把它与硬盘 ROS 直接横比。

内存原始特征包不入库。运行前由用户提供数据目录，使用 `benchmark/smartmem/prepare_data.py` 生成带 manifest、分区和审计摘要的运行目录。

## 新器件：同一 Skill 的迁移证据

公开光网络数据上的迁移只作为适配冒烟，不冒充榜单成绩：

- 从公开 Optical Network Fault Dataset 的 topology-1 before/after PM JSON 聚合出 222 个设备样本和 154 个数值特征；
- 通过 manifest 归一化后进入同一搜索流程，UCT budget=1 成功写出 JSONL 轨迹，根节点 full F1=0.850；这个分数使用临时工单时间，只证明接入链路可运行；
- 同一批数据写成 CSV、Parquet、Feather、Excel、JSON 和 log 后，统一读取行数均为 222；格式变化没有引入器件专用算法分支；
- 没有工单的数据使用同一 telemetry manifest 进入无标签异常检测，输出异常分数而不是伪造监督标签。

这项验证支持的结论是：算法、搜索、RAG、两档评估和审计轨迹共用；器件差异由 manifest 声明设备列、时间列、数值特征、事件列、lead/horizon、告警预算和分组键。它没有证明不同器件之间的分数可以直接比较。

## 证据与限制

- 原始数据、私有标签、holdout 和密钥不提交仓库；报告只保留配置摘要、公开数据链接和可复算路径。
- 本地测试不需要真实 API key；真实进化只从环境变量读取密钥。
- 所有对外数字都应带 split、是否参与搜索、运行时间和证据文件路径；没有这些字段的数字不能作为最佳结果介绍。
